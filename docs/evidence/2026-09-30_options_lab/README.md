# 期权 package 研究实验室（2026-09-30）

用途：为《Pi 期权 package 第一版研究框架》中关于定价库选型、隐含波动率计算与性能的判断提供可复现证据。全部使用合成输入，**不是任何 package 的运行验收**，也没有连接 IBKR。

## 环境

- Linux x86_64（Modal 沙箱），uv 0.9.28，CPython 3.12.12
- QuantLib 1.43、vollib 1.0.11（`py_vollib` 1.0.12 已标注弃用，提示改用 `vollib`）、numpy 2.5.3、scipy 1.18.1

## 复现

```bash
uv venv .venv --python 3.12 && uv pip install --python .venv/bin/python QuantLib vollib numpy scipy
.venv/bin/python option_libs.py > option_libs.json
```

## 结果（`option_libs.json`）

| 编号 | 问题 | 结果 |
| --- | --- | --- |
| E11 | 欧式 BSM 隐含波动率的精度与速度。合成链：S=100，r=4.5%，q=1%，到期 2 天至 2 年，行权价 60–140，带微笑曲线；剔除价格低于 0.005 的合约后剩 405 个 | vollib（Let's Be Rational 算法）约 0.019 ms/合约，QuantLib 解析引擎约 0.024 ms/合约。**按可识别性拆分**：价格对 1 个波动率点的敏感度（vega）≥ 0.01 的 288 个合约全部求解成功，误差约为 0；vega < 0.01 的合约有 18 个求解失败，其余误差最高达 38.9 个波动率点 |
| E12 | 用欧式公式反推美式价格的隐含波动率会有多大偏差（真实波动率 30%，r=4.5%） | 美式看跌（q=0）：半年期虚值 20% 为 +0.15 点，平值为 +0.72 点，实值 20% 为 +3.71 点，实值 30% 为 +7.94 点；一年期平值为 +1.19 点。美式看涨（连续股息 3%）：≤ 0.24 点 |
| E13 | 美式定价引擎的一致性与速度（看跌，r=4.5%，30% 波动率，18 个合约） | FD 400×400 约 7.5 ms/价；CRR 二叉树 801 步约 3.4 ms/价，与 FD 最大差 0.005；BAW 与 Bjerksund–Stensland 近似约 0.014–0.017 ms/价，但与 FD 最大差约 0.14（S=100）。QuantLib 内置的美式隐含波动率约 15.5 ms/合约。**价格等于内在价值的合约（例如实值 20–30%、30 天到期的看跌），隐含波动率无法识别**：内置方法一个失败、一个偏差 −1.84 点；用同一引擎自行求根，其余合约误差 < 0.01 点，但约 106 ms/合约 |

## 局限

输入是合成的常数或参数化波动率，只能说明算法精度与计算量级，不代表真实报价的噪声、价差和离散股息情形；计时为单线程，在 Linux 沙箱中测得。
